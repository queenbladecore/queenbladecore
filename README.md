## I'm queenbladecore 👋

I build terminal tools and low-level systems software, mostly in Rust and C. I get drawn to the layer where abstractions thin out and you are left staring at memory, syscalls, and tradeoffs nobody documented. Lately I've been obsessing over WebAssembly as a runtime for small, fast, composable components.
